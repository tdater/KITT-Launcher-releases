# KITT Launcher

A Knight Rider (KITT) themed home-screen launcher for Android car head units: OBD-II car scanner,
an AI co-pilot that sees your live vehicle data, map search with spoken directions, a browser for
streaming and AI chat, and the always-on red scanner light.

## Download

**[Get the latest APK](https://github.com/tdater/KITT-Launcher-releases/releases/latest)** (under *Assets*).

**[See everything it does](https://tdater.github.io/KITT-Launcher-releases/)**

## Install

1. Download the `.apk` on the head unit (or copy it over on a USB stick).
2. Open it and allow your browser or file manager to install unknown apps when Android asks.
3. Press Home and choose **KITT Launcher**, then **Always**, to make it the home screen.

Requires Android 7.0 or newer. Built for a 12.1" portrait head unit; landscape screens work too.

## Updates

KITT Config → Updates checks this page and installs newer versions for you.
